# VibeGuard AI

AI-powered code security scanning directly inside Visual Studio Code.

VibeGuard AI analyzes your code through a multi-stage security pipeline combining static analysis, sandbox execution, and AI-powered security analysis.

## Features

- 🔍 Static code analysis
- 🛡️ AI-powered security analysis
- 📦 Sandboxed execution
- ⚡ Fast security scanning
- 📊 Risk scoring and diagnostics
- 🧠 AI-generated security insights
- 💻 Works directly inside VS Code
